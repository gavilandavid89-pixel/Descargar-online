Guía de uso · MediaGrab Pro

Descargar imágenes y GIFs online

MediaGrab Pro puede analizar enlaces directos a imágenes públicas y mostrar una opción para guardar el archivo original cuando el tipo de archivo y el tamaño son compatibles.

Probar un enlace

Introduce la URL pública que quieres analizar. Te llevaremos al analizador con el enlace preparado.


Cómo descargar paso a paso

  1. Copia la dirección directa de la imagen o GIF público. Debe apuntar al archivo, no solo a una página que lo contiene.
  2. Pega la URL en el analizador y pulsa Analizar.
  3. Si se reconoce un archivo de imagen compatible, usa la opción de descarga.

Compatibilidad y limitaciones

  • Se admiten tipos de imagen comunes, como JPEG, PNG, WebP, GIF y AVIF, sujetos a validación del servidor.
  • Los archivos directos tienen un límite de tamaño de 20 MB; algunas páginas no exponen una URL directa de imagen.

Preguntas frecuentes

¿Puedo descargar GIFs?

Sí, cuando el enlace apunta directamente a un GIF público compatible y el servidor puede validarlo.

¿Puedo pegar el enlace de una página web?

La herramienta necesita una URL directa al archivo de imagen; un enlace a una página puede no ser suficiente.

¿Se modifica la calidad de la imagen?

La descarga directa intenta conservar el archivo original, sin convertirlo.
